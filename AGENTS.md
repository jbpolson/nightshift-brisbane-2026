# Codex Project Instructions

This is a simple static event website.

## Keep The Project Simple

- Edit `index.html` directly unless there is a clear reason to split files.
- Do not add React, Next.js, Tailwind, Vite, or a build step unless the project owner asks for it.
- Keep images and fonts inside `assets/`.
- Preserve the existing visual direction: black background, sharp event typography, high-contrast green accents, and cycling/event photography.

## Before Finishing A Change

- Preview the page in a browser.
- Check mobile width as well as desktop width.
- Confirm images still load.
- Confirm event details are consistent across the page.
- Keep each pull request focused on one clear change.

## Common Edits

- Event copy, dates, times, prices, sponsor details, and FAQs live in `index.html`.
- Image references point to files in `assets/images/`.
- Font references point to files in `assets/fonts/`.
